# AfriCare

**La santé, sans attendre.**

Application de gestion des files d'attente et de prise de rendez-vous dans les établissements de santé (version de démarrage — phase test Dakar).

## Lancer l'application

1. Ouvrez l'adresse GitHub Pages de ce dépôt (voir ci-dessous).
2. Sur **Android (Chrome)** : le bandeau « Installer » apparaît → appuyez pour ajouter l'icône à l'écran d'accueil.
3. Sur **iPhone (Safari)** : bouton Partager → « Sur l'écran d'accueil ».

## Contenu

- **Patient** : recherche médecin, créneaux, paiement (Wave / Orange Money / Carte / Apple Pay), ticket numérique, suivi de file en temps réel, notifications de progression.
- **Professionnel** : connexion sécurisée, vue du flux, actions Suivant / Absent / Pause.
- **Accueil** : multi-services, enregistrement des patients sans smartphone.

Logo officiel, couleurs #0259BC et #0BA251, interface calme et confidentielle.
